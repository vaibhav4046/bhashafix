# Changelog

All notable changes to BhashaFix are documented here.

## 0.2.0 — 2026-07-29

- Expanded the original narrow demo into a locale-agnostic pnpm workspace.
- Added the genuine AtlasPay 10→0 deterministic repair and regression proof.
- Added shared core, crawler, extractor, locale, linguistic, visual, repair,
  verifier, report, provider, CLI, and MCP packages.
- Added the full web workflow, public URL guardrails, report downloads, themes,
  responsive layouts, accessibility coverage, and replay artifacts.
- Added publishable CLI/MCP builds, GitHub Actions, open-source documentation,
  Playwright release tests, and a screenshot-backed hackathon package.

## 0.1.0 — 2026-07-29

- Initial BhashaFix five-defect proof-of-concept and Vercel deployment.
