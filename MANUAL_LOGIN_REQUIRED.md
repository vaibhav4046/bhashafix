# Manual organiser login required

The application, proof artifacts and deck can be prepared without access to the
organiser dashboard. The final submission button cannot be represented as
complete until the owner performs these authenticated steps:

1. Sign in to the official hackathon dashboard.
2. Confirm the registered team and submission deadline shown there.
3. Copy the reviewed answers from
   `submission/FINAL_SUBMISSION_FORM.md`.
4. Upload `submission/BhashaFix-Hackathon-Deck.pptx`.
5. Add the verified Vercel URL and the real GitHub URL after repository
   publication.
6. Review every claim and submit.
7. Save the organiser's actual confirmation receipt.

No organiser submission confirmation is included in this repository.
