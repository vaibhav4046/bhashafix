# Roadmap

## P0 — verified in this release

Shared deterministic engine, AtlasPay ten-defect fixture, web workspace, real
repair diff, identical-test verification, reports, CLI, local STDIO MCP, light
and dark themes, replay mode, tests, and hackathon submission package.

## P1 — next

- Browser-backed public URL crawling with sitemap and robots coverage.
- Glossary and translation-memory persistence in the web UI.
- Production adapters for Groq, OpenAI, Anthropic, and local compatible servers.
- Firefox and WebKit validation in supported environments.
- Richer pseudo-localisation and font-coverage probes.
- SARIF/JUnit annotations integrated directly into CI review surfaces.

## P2 — intentionally deferred

Authenticated SaaS accounts, teams, billing, remote MCP transport, enterprise
SSO, arbitrary automatic source repair, a browser extension, high-concurrency
cloud scanning, a translator marketplace, and full translation-management
replacement.

P2 will not be presented as implemented until it has real security, reliability,
and tenancy verification.
