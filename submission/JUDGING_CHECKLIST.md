# Judging checklist

- [x] Problem is understandable in under 20 seconds.
- [x] One-line pitch and visible URL scan action above the fold.
- [x] Original Living Language visual identity, dark/light themes, reduced motion.
- [x] Genuine AtlasPay ten-failure baseline.
- [x] Every issue contains stable ID, locale, route, predicate, and evidence.
- [x] Real bounded three-file unified diff.
- [x] Identical-test rerun reaches zero blocking issues.
- [x] en-GB source-locale regression passes.
- [x] Web, CLI, MCP, and CI call shared engine contracts.
- [x] No provider key required for deterministic or replay mode.
- [x] SSRF, path traversal, symlink, secret, CSP, and repair controls implemented.
- [x] JSON, HTML, SARIF, JUnit, CSV, proof, and patch downloads.
- [x] Desktop 1440×900 and mobile 390×844 browser tests.
- [x] Dark, light, reduced motion, accessibility, and console tests.
- [x] Actual screenshots used in the submission package.
- [x] Apache-2.0 licence and complete open-source documentation.
- [ ] Public GitHub URL added after authenticated publication.
- [ ] Organizer form submitted and confirmation captured manually.

The unchecked items are external authentication boundaries, not local product
failures.
