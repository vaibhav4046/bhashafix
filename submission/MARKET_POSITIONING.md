# Market positioning

## Category

Open-source localisation engineering, linguistic quality, and visual
verification.

## Wedge

Translation systems translate and manage strings. BhashaFix verifies the
rendered production boundary: meaning, placeholders, terminology, locale
metadata, direction, font coverage, overflow, accessibility, and regression.

## Users

Founders and product managers need release confidence. Developers need source
hints and bounded diffs. Localisation teams need terminology and context.
QA teams need reproducible browser evidence. Coding agents need strict tools
instead of guessing whether localisation is complete.

## Differentiation

- One evidence contract shared by web, CLI, CI, and MCP.
- Deterministic findings separated from confidence-scoped linguistic judgement.
- Repair accepted only after identical predicates and source regression pass.
- Provider-independent and useful in no-AI mode.
- Local-first files, no mandatory database, and an Apache-2.0 core.

## Honest position

BhashaFix is not a full translation-management system and does not claim perfect
native fluency. It is the specialised verification harness that translation
tools and general coding agents can call before release.

No market size, customer, revenue, partnership, adoption, or benchmark claims
are included because none were independently established for this MVP.
